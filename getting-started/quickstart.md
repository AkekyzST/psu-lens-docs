# Login with PSU Passport ลงชื่อเข้าใช้

<figure><img src="../.gitbook/assets/image (6).png" alt=""><figcaption><p>หน้าแรกของระบบ</p></figcaption></figure>

## Getting Started

เริ่มต้นการใช้งานระบบด้วยการลงชื่อเข้าใช้โดยการ กดปุ่ม Login with PSU Passport, ระบบจะนำทางผู้ใช้ไปสู่เว็ปไซต์กลางสำหรับการลงชื่อเข้าใช้ระบบของมหาวิทยาลัยสงขลานครินทร์

<figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>

## ช่องทางในการลงชื่อเข้าใช้

1. ลงชื่อเข้าใช้ด้วย PSU Passport Account
   1. นักศึกษาลงชื่อเข้าใช้ด้วย รหัสนักศึกษา หรือ Email ของนักศึกษา (`รหัสนักศึกษา@email.psu.ac.th` หรือ `รหัสนักศึกษา@psu.ac.th` ขึ้นกับปีที่เข้าศึกษา)
   2. อาจารย์ / บุคลากร  ลงชื่อเข้าใช้ด้วย PSU Passport ID หรือ Email ของบุคลากร (`Passport ID@psu.ac.th`)
2. ลงชื่อเข้าใช้ด้วย Microsoft 365 Account โดยการกดปุ่ม PSU Microsoft 365 ถัดจากปุ่ม Log In

{% hint style="info" %}
รายละเอียดเพิ่มเติมสำหรับคู่มือการใช้งานระบบลงชื่อเข้าใช้ PSU One Passport สามารถ Scan QR Code ได้จากภาพพื้นหลังหรือเข้าผ่าน URL:  link.psu.th/QRdHNQ  เขียนโดยสำนักนวัตกรรมดิจิทัลและระบบอัจฉริยะ&#x20;
{% endhint %}
