# Login with PSU Passport ลงชื่อเข้าใช้

<figure><img src="../.gitbook/assets/v2-login.png" alt=""><figcaption><p>หน้าแรกของระบบ PSU Assessment Lens และปุ่มเข้าสู่ระบบด้วย PSU Passport</p></figcaption></figure>

## เริ่มต้นใช้งาน

เริ่มใช้งานได้ง่าย ๆ เพียงกดปุ่ม **PSU Passport** ที่หน้าแรก ระบบจะพาท่านไปยังหน้าลงชื่อเข้าใช้กลางของมหาวิทยาลัยสงขลานครินทร์ (PSU Passport) เมื่อยืนยันตัวตนเรียบร้อยแล้ว ระบบจะพาท่านกลับเข้าสู่ PSU Assessment Lens ให้โดยอัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม

## ใช้บัญชีอะไรเข้าสู่ระบบ

ระบบใช้บัญชี **PSU Passport** เพียงช่องทางเดียว จึงไม่ต้องสมัครสมาชิกใหม่ และระบบประเมินก็ไม่ได้เก็บรหัสผ่านของท่านไว้ ท่านใช้บัญชีเดิมที่ใช้กับบริการอื่น ๆ ของมหาวิทยาลัยได้เลย

* **นักศึกษา** เข้าสู่ระบบด้วยรหัสนักศึกษา หรืออีเมลของนักศึกษา (`รหัสนักศึกษา@email.psu.ac.th` หรือ `รหัสนักศึกษา@psu.ac.th` แล้วแต่ปีที่เข้าศึกษา)
* **อาจารย์ / บุคลากร** เข้าสู่ระบบด้วย PSU Passport ID หรืออีเมลของบุคลากร (`Passport ID@psu.ac.th`)

{% hint style="info" %}
**ลืมรหัสผ่าน PSU Passport?** ไม่ต้องกังวล ตั้งรหัสผ่านใหม่ได้เองที่ [onepassport.psu.ac.th](https://onepassport.psu.ac.th) หรือกดลิงก์ "ลืมรหัสผ่าน" ที่หน้าแรกของระบบ หากยังเข้าใช้งานไม่ได้ ติดต่อศูนย์คอมพิวเตอร์ของวิทยาเขตของท่านได้เลย
{% endhint %}

{% hint style="info" %}
ปรับหน้าจอให้ถูกใจได้ตามสะดวก — ที่หน้าแรกและแถบด้านบนของระบบ ท่านสลับ **โหมดสว่าง/มืด** และเปลี่ยน **ภาษา (ไทย/อังกฤษ)** ได้ตลอดเวลา
{% endhint %}
