# ผลการประเมินรายวิชา

<figure><img src="../.gitbook/assets/Screenshot 2025-01-30 223725_censored_via_10015_io.png" alt=""><figcaption><p>รูปภาพแสดงการค้นหารายวิชาเพื่อดูผลการประเมิน</p></figcaption></figure>

ผู้ใช้สามารถดูผลการประเมินรายวิชาได้ทั้งหมดที่อยู่ภายใต้สังกัดของท่าน ซึ่งสามารถค้นหารายวิชาด้วยการกรองวิทยาเขต คณะ ภาควิชา ภาคการศึกษาและคำค้นหา (รหัสวิชาหรือชื่อวิชา) ได้

ระบบจะแสดงรายวิชา ในแต่ละรายวิชาจะประกอบไปด้วย รหัสวิชา ชื่อวิชา ตอน ภาคการศึกษา ปีการศึกษา จำนวนผู้ทำใบประเมิน % ของการทำใบประเมิน คะแนนเฉลี่ยในแต่ละประเภทการประเมิน และสามารถดูรายละเอียดรายวิชาได้เช่น สังกัดที่ไหน สอนโดยใคร มี CLOs อะไรบ้าง

<figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption><p>รูปภาพแสดงผลการประเมินในรูปแบบตาราง</p></figcaption></figure>

ผู้ใช้สามารถกดดูผลการประเมินในรูปแบบตารางได้ หรือ Download รายงานผลในรูปแบบของไฟล์ Excel (.xlsx) ซึ่งทั้ง 2 ส่วนจะเหมือนกับหน้าตาของอาจารย์ในหน้าผลการประเมิน

<figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>

ผู้ใช้สามารถดาวน์โหลดรายงานความคืบหน้าในการประเมินของทุกรายวิชาที่ค้นหาไว้อยู่ได้ สามารถดาวน์โหลดรายงานผลการประเมินแบบภาพรวมตามการค้นหารายวิชา และสามารถดาวน์โหลดรายงานความคิดเห็นทั้งหมดของทุกรายวิชาที่ค้นหาไว้อยู่ออกมาในรูปแบบไฟล์ Excel (.xlsx) ได้โดยการกดปุ่มดังกล่าวที่อยู่ถัดจากกล่องค้นหารายวิชา

{% hint style="info" %}
ผลลัพธ์ของรายงานจะขึ้นกับการต้นหารายวิชา หากต้องการดูภาพรวมทั้งหมดให้ค้นหาแบบไม่ระบุวิทยาเขต คณะ ภาควิชาและคำค้นหา ในกรณีที่ท่านสังกัดระดับวิทยาเขตหรือคณะ ระบบจะ default ให้เห็นตามขอบเขตของท่านเท่านั้น
{% endhint %}
