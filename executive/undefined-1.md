# ผลการประเมินรายวิชา

<figure><img src="../.gitbook/assets/v2-executive-result.png" alt=""><figcaption><p>หน้าค้นหาและผลการประเมินรายวิชาในรูปแบบตาราง พร้อมปุ่มดาวน์โหลดรายงาน</p></figcaption></figure>

ผู้บริหารสามารถดูผลการประเมินรายวิชาทั้งหมดที่อยู่ภายใต้สังกัดของท่าน โดยค้นหาด้วยตัวกรอง วิทยาเขต คณะ ภาควิชา ภาคการศึกษา และคำค้นหา (รหัสวิชาหรือชื่อวิชา)

ระบบจะแสดงรายวิชาพร้อมรหัสวิชา ชื่อวิชา ตอน ภาคการศึกษา ปีการศึกษา จำนวนผู้ทำใบประเมิน สัดส่วน % ของการทำใบประเมิน และคะแนนเฉลี่ยของแต่ละประเภทการประเมิน อีกทั้งดูรายละเอียดรายวิชาได้ เช่น สังกัด อาจารย์ผู้สอน และผลลัพธ์การเรียนรู้ (CLO)

ท่านสามารถกดดูผลการประเมินในรูปแบบตาราง หรือดาวน์โหลดรายงานเป็นไฟล์ Excel (.xlsx) ซึ่งหน้าตาเหมือนกับหน้าผลการประเมินของอาจารย์

นอกจากนี้ยังดาวน์โหลดรายงานภาพรวมตามผลการค้นหาได้ ทั้งรายงานความคืบหน้าการประเมินของทุกรายวิชาที่ค้นหา รายงานผลการประเมินแบบภาพรวม และรายงานความคิดเห็นทั้งหมด ในรูปแบบไฟล์ Excel (.xlsx) โดยกดปุ่มที่อยู่ถัดจากกล่องค้นหารายวิชา

{% hint style="info" %}
ผลของรายงานจะขึ้นกับเงื่อนไขการค้นหา หากต้องการภาพรวมทั้งหมดให้ค้นหาแบบไม่ระบุวิทยาเขต คณะ ภาควิชา และคำค้นหา ทั้งนี้ หากท่านสังกัดระดับวิทยาเขตหรือคณะ ระบบจะกำหนดขอบเขตเริ่มต้นให้เห็นเฉพาะสังกัดของท่านเท่านั้น
{% endhint %}
