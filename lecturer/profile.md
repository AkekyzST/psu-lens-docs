# Profile ตั้งค่าโปรไฟล์

<figure><img src="../.gitbook/assets/v2-profile.png" alt=""><figcaption><p>หน้าตั้งค่าบัญชีของฉัน: ข้อมูลบัญชี รายการสิทธิ์การใช้งาน และการอัปโหลดรูปภาพ</p></figcaption></figure>

เข้าหน้านี้ได้จากมุมขวาบนของระบบ กดที่ชื่อของท่านแล้วเลือกโปรไฟล์ ระบบจะพามาที่หน้า **"ตั้งค่าบัญชีของฉัน"** ซึ่งรวมข้อมูลบัญชี (ชื่อไทย/อังกฤษ อีเมล ชื่อผู้ใช้) สังกัด (ภาควิชา · คณะ · วิทยาเขต) และสิทธิ์การใช้งานของท่านไว้ในที่เดียว

## สลับสิทธิ์การใช้งาน

บางท่านมีมากกว่าหนึ่งบทบาท (เช่น เป็นทั้งอาจารย์และเจ้าหน้าที่) ระบบจะแสดงบทบาททั้งหมดให้เห็น บทบาทที่ใช้อยู่จะขึ้นว่า **"กำลังใช้งานในสิทธิ์นี้"** ส่วนบทบาทอื่นจะมีปุ่ม **"ใช้บทบาทนี้"** กดแล้วยืนยันเพื่อสลับได้ทันที ไม่ต้องออกจากระบบให้ยุ่งยาก

## รูปภาพประจำตัว

อาจารย์ (และผู้ประสานงานรายวิชา) อัปโหลดรูปประจำตัวได้ ขนาดไม่เกิน **5 MB** รองรับไฟล์ `.jpg` และ `.png` รูปนี้จะไปแสดงให้นักศึกษาเห็นตอนประเมินการสอนของอาจารย์ และกดลบออกได้ทุกเมื่อ

{% hint style="warning" %}
แนะนำให้ใช้รูปที่เห็นใบหน้าชัดเจนและเหมาะสม เพื่อให้นักศึกษาจำได้และประเมินได้ตรงคน
{% endhint %}

{% hint style="info" %}
นักศึกษาไม่ต้องอัปโหลดรูปโปรไฟล์ เพราะคำตอบการประเมินถูกเก็บเป็นความลับอยู่แล้ว
{% endhint %}
