# Profile ตั้งค่าโปรไฟล์

<figure><img src="../.gitbook/assets/v2-profile.png" alt=""><figcaption><p>หน้าตั้งค่าบัญชีของฉัน: ข้อมูลบัญชี รายการสิทธิ์การใช้งาน และการอัปโหลดรูปภาพ</p></figcaption></figure>

เข้าหน้านี้ได้จากมุมขวาบนของระบบ กดที่รูปโปรไฟล์ (ตัวย่อชื่อ) จะเห็นเมนูที่แสดงชื่อของท่านและบทบาทที่ใช้อยู่พร้อมขอบเขต (วิทยาเขต › คณะ › ส่วนงาน) กดที่ชื่อหรือบทบาทเพื่อเข้าหน้า **"ตั้งค่าบัญชีของฉัน"** ซึ่งรวมข้อมูลบัญชี (ชื่อไทย/อังกฤษ อีเมล ชื่อผู้ใช้) สังกัด (ภาควิชา · คณะ · วิทยาเขต) และสิทธิ์การใช้งานของท่านไว้ในที่เดียว

<figure><img src="../.gitbook/assets/v2-profile-menu.png" alt=""><figcaption><p>เมนูโปรไฟล์มุมขวาบน: ชื่อ บทบาทที่ใช้อยู่ ปุ่มสลับบทบาท และออกจากระบบ</p></figcaption></figure>

บนจอคอมพิวเตอร์ ถัดจากรูปโปรไฟล์จะมีป้ายบอกบทบาทที่ใช้อยู่และวิทยาเขต (วางเมาส์ค้างเพื่อดูขอบเขตเต็ม) ส่วนบนมือถือ ชื่อและบทบาทจะอยู่ด้านบนของเมนูด้านข้างแทน

## สลับสิทธิ์การใช้งาน

บางท่านมีมากกว่าหนึ่งบทบาท (เช่น เป็นทั้งอาจารย์และผู้บริหาร) สลับได้ 2 ทาง ไม่ต้องออกจากระบบ

* **จากเมนูโปรไฟล์** กด **"สลับบทบาท…"** (ปุ่มนี้จะมีเฉพาะผู้ที่มีมากกว่าหนึ่งบทบาท) แล้วเลือกบทบาทในหน้าต่างที่เปิดขึ้น
* **จากหน้าตั้งค่าบัญชี** ในส่วน **"สิทธิ์การใช้งาน"** ระบบแสดงบทบาททั้งหมดพร้อมขอบเขต บทบาทที่ใช้อยู่จะขึ้นว่า **"กำลังใช้งาน"** ส่วนบทบาทอื่นจะมีปุ่ม **"ใช้บทบาทนี้"**

กดแล้วระบบจะถามยืนยันอีกครั้ง เมื่อยืนยัน หน้าเว็บจะโหลดใหม่ เมนูด้านข้างและข้อมูลที่เห็นจะเปลี่ยนตามบทบาทใหม่ทันที

## รูปภาพประจำตัว

อาจารย์ (และผู้ประสานงานรายวิชา) อัปโหลดรูปประจำตัวได้ ขนาดไม่เกิน **5 MB** รองรับไฟล์ `.jpg` และ `.png` รูปนี้จะไปแสดงให้นักศึกษาเห็นตอนประเมินการสอนของอาจารย์ (ดูตัวอย่างได้ที่ [ส่วนประเมินอาจารย์](../student/evaluation.md#3.-ประเมินอาจารย์)) และกดลบออกได้ทุกเมื่อ

{% hint style="warning" %}
แนะนำให้ใช้รูปที่เห็นใบหน้าชัดเจนและเหมาะสม เพื่อให้นักศึกษาจำได้และประเมินได้ตรงคน
{% endhint %}

{% hint style="info" %}
นักศึกษาไม่ต้องอัปโหลดรูปโปรไฟล์ เพราะคำตอบการประเมินถูกเก็บเป็นความลับอยู่แล้ว
{% endhint %}
