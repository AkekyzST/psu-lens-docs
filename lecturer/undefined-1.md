# ผลการประเมินรายวิชา

<figure><img src="../.gitbook/assets/v2-lecturer-result.png" alt=""><figcaption><p>หน้าผลการประเมินรายวิชา: การ์ดตัวชี้วัด กราฟ และผลรายหัวข้อ</p></figcaption></figure>

หน้าผลการประเมินรายวิชาจะแสดงหัวเรื่องรายวิชา (รหัสวิชา ตอน ชื่อวิชา) และแถวตัวชี้วัด ได้แก่

* **สัดส่วนผู้ตอบ** — จำนวนผู้ทำใบประเมินเทียบกับจำนวนนักศึกษาที่ลงทะเบียน พร้อมแถบความคืบหน้า
* **คะแนนเฉลี่ย** ของแต่ละประเภทการประเมิน (รายวิชา/ชุดวิชา, ทวนสอบผลสัมฤทธิ์, การสอนอาจารย์) — กดที่การ์ดคะแนนเพื่อสลับไปดูผลของประเภทนั้น ๆ ได้ โดยคะแนนการประเมินอาจารย์จะแสดงเป็นคะแนนเฉลี่ยแบบปรับฐาน (เต็ม 5) ด้วย

ระบบจะแสดงกราฟแท่งของคะแนนเฉลี่ยในแต่ละหัวข้อ พร้อมแถบเครื่องมือที่มีปุ่ม **ดาวน์โหลดรายงาน**, ปุ่ม **ข้อเสนอแนะจากผู้ประเมิน** (พร้อมตัวเลขจำนวนความคิดเห็น) และปุ่มสลับ **มุมมองรายการ / มุมมองตาราง**

<figure><img src="../.gitbook/assets/v2-lecturer-result-table.png" alt=""><figcaption><p>การแสดงผลการประเมินในมุมมองตาราง</p></figcaption></figure>

ข้อเสนอแนะทั้งหมดจากนักศึกษาสามารถกดอ่านได้จากปุ่ม **ข้อเสนอแนะจากผู้ประเมิน** โดยระบบจะไม่แสดงชื่อของผู้ให้ความคิดเห็น แยกเป็นข้อเสนอแนะเกี่ยวกับรายวิชา และข้อเสนอแนะเกี่ยวกับอาจารย์ผู้สอน

<figure><img src="../.gitbook/assets/v2-lecturer-result-comments.png" alt=""><figcaption><p>หน้าต่างอ่านข้อเสนอแนะจากนักศึกษา (ไม่แสดงชื่อผู้ให้ความคิดเห็น)</p></figcaption></figure>

## รายงานผล (ไฟล์ Excel)

ไฟล์รายงานผลจะออกมาในรูปแบบไฟล์ Excel (.xlsx) ประกอบด้วย 4 sheet

* Sheet 1 — "ผลการประเมินรายวิชา-ชุดวิชา" (รายละเอียดรายวิชาและผลการประเมินรายวิชา)
* Sheet 2 — "ผลการประเมินทวนสอบผลสัมฤทธิ์"
* Sheet 3 — "ผลการประเมินการสอนอาจารย์"
* Sheet 4 — "ข้อคิดเห็นหรือข้อเสนอแนะ" (ข้อคิดเห็นทั้งหมด)

{% hint style="info" %}
กรณีรายวิชามีอาจารย์ผู้สอนมากกว่า 1 ท่าน อาจารย์ผู้ประสานงานรายวิชา (ซึ่งถูกกำหนดให้เป็นอาจารย์ผู้สอน **ลำดับที่ 1** ของตอนเรียน) จะเห็นคะแนนและความคิดเห็นของอาจารย์ทุกท่าน ส่วนอาจารย์ท่านอื่นจะเห็นเฉพาะข้อมูลการประเมินของตนเองเท่านั้น
{% endhint %}

{% hint style="warning" %}
หากรายวิชานั้นยังปิดการตั้งค่าการมองเห็นผลไว้ ระบบจะยังไม่แสดงผลลัพธ์ และจะขึ้นข้อความว่ารายวิชานี้ยังไม่สามารถดูผลลัพธ์การประเมินได้
{% endhint %}
