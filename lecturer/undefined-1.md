# ผลการประเมินรายวิชา

<figure><img src="../.gitbook/assets/v2-lecturer-result.png" alt=""><figcaption><p>หน้าผลการประเมินรายวิชา: การ์ดตัวชี้วัด กราฟ และผลรายหัวข้อ</p></figcaption></figure>

หน้าผลการประเมินรายวิชาสรุปทุกอย่างไว้ให้ครบ เริ่มจากหัวเรื่องรายวิชา (รหัสวิชา ตอน ชื่อวิชา) และแถวการ์ดตัวชี้วัดด้านบน ได้แก่

* **สัดส่วนผู้ตอบ** — จำนวนผู้ทำใบประเมินเทียบกับจำนวนนักศึกษาที่ลงทะเบียน พร้อมแถบความคืบหน้าให้เห็นภาพ
* **คะแนนเฉลี่ย** ของแต่ละประเภท (รายวิชา/ชุดวิชา, ทวนสอบผลสัมฤทธิ์, การสอนอาจารย์) กดที่การ์ดคะแนนเพื่อสลับไปดูผลของประเภทนั้น ๆ ได้ ทั้งนี้คะแนนการประเมินอาจารย์จะแสดงเป็นค่าที่ปรับให้เทียบเป็นเต็ม 5 ด้วย เพื่อให้เทียบกันได้สะดวก

ด้านล่างเป็นกราฟแท่งคะแนนเฉลี่ยรายหัวข้อ พร้อมแถบเครื่องมือที่มีปุ่ม **ดาวน์โหลดรายงาน**, ปุ่ม **ข้อเสนอแนะจากผู้ประเมิน** (มีตัวเลขบอกจำนวนความคิดเห็น) และปุ่มสลับ **มุมมองรายการ / มุมมองตาราง** เลือกดูแบบที่ถนัดได้เลย

<figure><img src="../.gitbook/assets/v2-lecturer-result-table.png" alt=""><figcaption><p>การแสดงผลการประเมินในมุมมองตาราง</p></figcaption></figure>

อยากอ่านความเห็นจากนักศึกษาแบบเต็ม ๆ กดปุ่ม **ข้อเสนอแนะจากผู้ประเมิน** ได้เลย ระบบจะไม่แสดงชื่อผู้ให้ความคิดเห็น และแยกให้ชัดระหว่างข้อเสนอแนะเกี่ยวกับรายวิชา กับข้อเสนอแนะเกี่ยวกับอาจารย์ผู้สอน

<figure><img src="../.gitbook/assets/v2-lecturer-result-comments.png" alt=""><figcaption><p>หน้าต่างอ่านข้อเสนอแนะจากนักศึกษา (ไม่แสดงชื่อผู้ให้ความคิดเห็น)</p></figcaption></figure>

## รายงานผล (ไฟล์ Excel)

อยากเก็บผลไว้ใช้ต่อ ดาวน์โหลดรายงานเป็นไฟล์ Excel (.xlsx) ได้ ในไฟล์มี 4 ชีต ครบทุกมุม

* ชีตที่ 1 — "ผลการประเมินรายวิชา-ชุดวิชา" (รายละเอียดรายวิชาและผลการประเมินรายวิชา)
* ชีตที่ 2 — "ผลการประเมินทวนสอบผลสัมฤทธิ์"
* ชีตที่ 3 — "ผลการประเมินการสอนอาจารย์"
* ชีตที่ 4 — "ข้อคิดเห็นหรือข้อเสนอแนะ" (ข้อคิดเห็นทั้งหมด)

{% hint style="info" %}
ถ้าวิชาหนึ่งมีอาจารย์ผู้สอนหลายท่าน อาจารย์ผู้ประสานงานรายวิชา (ซึ่งถูกกำหนดให้เป็นอาจารย์ผู้สอน **ลำดับที่ 1** ของตอนเรียน) จะเห็นคะแนนและความคิดเห็นของอาจารย์ทุกท่าน ส่วนอาจารย์ท่านอื่นจะเห็นเฉพาะผลของตนเองเท่านั้น
{% endhint %}

{% hint style="warning" %}
ถ้ายังปิดการตั้งค่าการมองเห็นผลของวิชานั้นไว้ ระบบจะยังไม่แสดงผล และจะขึ้นข้อความว่าวิชานี้ยังดูผลลัพธ์ไม่ได้ รอเปิดการมองเห็นก่อนนะครับ/คะ
{% endhint %}
