# ภาพรวมผลการประเมินและรายวิชาที่สอน

<figure><img src="../.gitbook/assets/v2-lecturer-home.png" alt=""><figcaption><p>หน้าแรกของอาจารย์: ภาพรวมคะแนนและรายวิชาที่สอน</p></figcaption></figure>

เมื่ออาจารย์เข้าสู่ระบบ หน้าแรกจะทักทายท่านพร้อมบอกสิทธิ์การใช้งาน คณะ/วิทยาเขต และภาคการศึกษาปัจจุบัน พร้อมปุ่มลัด **"รายวิชาของฉัน"** ให้กดเข้าไปดูวิชาที่สอนได้ทันที

ถัดลงมาเป็นภาพรวมคะแนนเฉลี่ยของการประเมินแต่ละประเภท ช่วยให้ท่านเห็นผลโดยรวมได้ในหน้าเดียว

* คะแนนเฉลี่ยการประเมินรายวิชา/ชุดวิชา
* ผลการประเมินทวนสอบผลสัมฤทธิ์ทางการเรียน ระบบเชื่อมกับ Course Spec. และแปลผลออกมาเป็นระดับผลสัมฤทธิ์ คือ ตั้งแต่ 50% ขึ้นไป หรือ ต่ำกว่า 50%
* คะแนนเฉลี่ยการประเมินการสอนของอาจารย์ โดยจะไม่นับผู้ที่เลือก N/A หรือไม่แสดงความคิดเห็นมารวมในค่าเฉลี่ย ตัวเลขจึงสะท้อนเฉพาะผู้ที่ให้คะแนนจริง

## รายวิชา/ชุดวิชาที่สอน

ระบบจะแสดงรายวิชาทั้งหมดที่ท่านสอน แต่ละวิชาบอกรหัสวิชา ชื่อวิชา ตอน สัดส่วนนักศึกษาที่ส่งแบบประเมินแล้วเทียบกับจำนวนที่ลงทะเบียน และสถานะช่วงการประเมิน

{% hint style="info" %}
เพื่อความเป็นธรรมและความลับของผู้ประเมิน อาจารย์จะเข้าดูผลได้หลังจากพ้นช่วงการประเมิน **และ** มีการเปิด/ส่งระดับคะแนนของรายวิชานั้นแล้วเท่านั้น
{% endhint %}

<figure><img src="../.gitbook/assets/v2-lecturer-courses.png" alt=""><figcaption><p>รายวิชาที่สอน แสดงสัดส่วนผู้ส่งใบประเมินและคะแนนเฉลี่ยเมื่อผลถูกเปิดให้ดูแล้ว</p></figcaption></figure>

เมื่อพ้นช่วงการประเมินและผลถูกเปิดให้ดูแล้ว การ์ดรายวิชาจะเปลี่ยนมาแสดงคะแนนเฉลี่ย กดเข้าไปดูผลการประเมินแบบละเอียดได้เลย
