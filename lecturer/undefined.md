# ภาพรวมผลการประเมินและรายวิชาที่สอน

<figure><img src="../.gitbook/assets/v2-lecturer-home.png" alt=""><figcaption><p>หน้าแรกของอาจารย์: ภาพรวมคะแนนและรายวิชาที่สอน</p></figcaption></figure>

หน้าแรกของอาจารย์จะแสดงแถบต้อนรับพร้อมสิทธิ์การใช้งาน คณะ/วิทยาเขต และภาคการศึกษาปัจจุบัน พร้อมปุ่มลัดไปยัง **"รายวิชาของฉัน"**

ถัดลงมาเป็นภาพรวมคะแนนเฉลี่ยของการประเมินแต่ละประเภท

* คะแนนเฉลี่ยการประเมินรายวิชา/ชุดวิชา
* ผลการประเมินทวนสอบผลสัมฤทธิ์ทางการเรียน โดยระบบเชื่อมต่อกับ Course Spec. และแปลผลเป็นผลสัมฤทธิ์ มากกว่าหรือเท่ากับ 50% หรือ น้อยกว่า 50%
* คะแนนเฉลี่ยการประเมินการสอนของอาจารย์ โดยการคำนวณค่าเฉลี่ยจะไม่นำผู้ที่ให้คะแนน N/A หรือไม่แสดงความคิดเห็นมาคิด

## รายวิชา/ชุดวิชาที่สอน

ระบบจะแสดงรายวิชาทั้งหมดที่ท่านสอน แต่ละวิชาจะแสดงรหัสวิชา ชื่อวิชา ตอน สัดส่วนผู้ที่ส่งแบบประเมินแล้วต่อจำนวนนักศึกษาที่ลงทะเบียน และสถานะช่วงการประเมิน

{% hint style="info" %}
อาจารย์จะเข้าดูผลการประเมินได้หลังจากพ้นช่วงการประเมิน **และ** มีการเปิด/ส่งระดับคะแนนของรายวิชานั้นแล้วเท่านั้น
{% endhint %}

<figure><img src="../.gitbook/assets/v2-lecturer-courses.png" alt=""><figcaption><p>รายวิชาที่สอน แสดงสัดส่วนผู้ส่งใบประเมินและคะแนนเฉลี่ยเมื่อผลถูกเปิดให้ดูแล้ว</p></figcaption></figure>

หลังจากพ้นช่วงการประเมินและผลถูกเปิดให้ดูแล้ว การ์ดรายวิชาจะแสดงคะแนนเฉลี่ย และสามารถกดเข้าไปดูผลการประเมินโดยละเอียดได้
