# ภาพรวมผลการประเมินและรายวิชาที่สอน

<figure><img src="../.gitbook/assets/Screenshot 2025-01-29 223233_censored_via_10015_io.png" alt=""><figcaption><p>รูปภาพแสดงการแปลผลภาพรวมของอจารย์และรายวิชาที่สอน</p></figcaption></figure>

ในหน้าแรกของอาจารย์ ระบบจะแสดงจะแสดงภาพรวมของการประเมิน แบ่งการแสดงผลคะแนนเฉลี่ยของการประเมินแต่ละประเภท

* คะแนนเฉลี่ยประเมินรายวิชา/ชุดวิชา คะแนนเต็ม 5.00 คะแนน
* คะแนนเฉลี่ยประเมินทวนสอบผลสัมฤทธิ์ทางการเรียน คะแนนเต็ม 100.00%
  * ระบบประเมินจะเชื่อมต่อกับระบบ Course Spec. และแปลผลคะแนนส่วนนี้เป็น ผลสัมฤทธิ์ทางการเรียน มากกว่าหรือเท่ากับ 50.00% หรือ น้อยกว่า 50.00%&#x20;
* คะแนนเฉลี่ยประเมินการสอนอาจารย์ คะแนนเต็ม 4.00 คะแนน
  * ผลการคำนวนค่าเฉลี่ยจะไม่นำผู้ที่ให้คะแนน N/A หรือไม่ออกความคิดเห็นมาแสดง

## รายวิชา/ชุดวิชาที่สอน

ระบบจะแสดงรายวิชาทั้งหมดที่ท่านสอน ในแต่ละวิชาจะแสดง รหัสวิชา ชื่อวิชา ตอน สัดส่วนผู้ที่ส่งใบประเมินแล้วต่อจำนวนนักศึกษาที่ลงทะเบียนในรายวิชา และสถานะช่วงการประเมิน

{% hint style="info" %}
อาจารย์สามารถเข้าไปดูผลการประเมินได้หลังจากพ้นช่วงการประเมินไปแล้วเท่านั้น
{% endhint %}

<figure><img src="../.gitbook/assets/Screenshot 2025-01-30 213654_censored_via_10015_io.png" alt=""><figcaption><p>รูปภาพแสดงการ์ดรายวิชาที่กำลังอยู่ในช่วงการประเมิน</p></figcaption></figure>

หลังจากพ้นช่วงการประเมินไปแล้ว ระบบจะเปลี่ยนการแสดงสถานะเป็นคะแนนเฉลี่ยประเมินรายวิชาและคะแนนเฉลี่ยประเมินอาจารย์ และสามารถกดเพื่อเข้าไปดูผลการประเมินได้
