# ใบประเมินอื่น ๆ ที่เกี่ยวข้องกับท่าน

นอกจากประเมินรายวิชาแล้ว บางครั้งเจ้าหน้าที่หรือหน่วยงานอาจสร้าง **แบบประเมินอื่น ๆ** ขึ้นมาและมอบหมายให้ท่านทำ เช่น แบบสำรวจหรือแบบประเมินเฉพาะกิจต่าง ๆ เข้าถึงได้จากเมนู **"แบบประเมินอื่น ๆ"** ทางแถบด้านซ้าย ซึ่งเมนูนี้มีให้ผู้ใช้ทุกสิทธิ์

{% hint style="info" %}
แบบประเมินเหล่านี้จะโผล่มาก็ต่อเมื่อท่านมีชื่ออยู่ในรายชื่อผู้ที่ต้องทำเท่านั้น ถ้ายังไม่มีใครมอบหมายให้ รายการก็จะว่างไว้ก่อน ไม่ต้องกังวล
{% endhint %}

## รายการแบบประเมิน

<figure><img src="../.gitbook/assets/v2-student-other.png" alt=""><figcaption><p>หน้าแบบประเมินอื่น ๆ เมื่อยังไม่มีแบบประเมินที่ได้รับมอบหมาย</p></figcaption></figure>

แบบประเมินที่มอบหมายให้ท่านจะแสดงเป็นการ์ด แบ่งเป็น 2 กลุ่ม เห็นชัดว่าอันไหนทำแล้วอันไหนยัง

* **กำลังดำเนินการ** — ยังไม่ได้ส่ง
* **ดำเนินการเสร็จสิ้น** — ส่งเรียบร้อยแล้ว

แต่ละการ์ดจะบอกชื่อแบบประเมิน ผู้สร้าง และช่วงเวลาที่เปิดให้ทำ กดที่การ์ดเพื่อเข้าไปทำได้เลย

## การทำและส่งแบบประเมิน

ในหน้าแบบประเมินจะบอกชื่อและคำอธิบายของแบบประเมิน ผู้สร้าง (**สร้างแบบประเมินโดย**) และช่วงเวลาที่เปิดให้ทำ พร้อมแถบความคืบหน้าและปุ่ม **บันทึก** / **ส่งใบประเมิน**

ตอบตามหัวข้อที่กำหนด ใส่ข้อเสนอแนะเพิ่มได้ตามสะดวก เมื่อกด **ส่งใบประเมิน** จะมีหน้าต่างให้ยืนยันอีกครั้ง

{% hint style="warning" %}
ส่งแล้วแก้ไขคำตอบไม่ได้อีก ตรวจทานให้เรียบร้อยก่อนกดยืนยันนะครับ/คะ
{% endhint %}
