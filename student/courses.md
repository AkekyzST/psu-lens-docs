# My Courses รายวิชาที่ลงทะเบียน

<figure><img src="../.gitbook/assets/v2-student-courses.png" alt=""><figcaption><p>รายวิชาทั้งหมดที่ลงทะเบียน จัดกลุ่มตามสถานะการประเมิน พร้อมช่องค้นหาและตัวกรอง</p></figcaption></figure>

หน้า **"รายวิชาที่ลงทะเบียน"** จะแสดงรายวิชาทั้งหมดที่นักศึกษาลงทะเบียนในภาคการศึกษาปัจจุบัน ท่านสามารถค้นหาด้วยรหัสวิชาหรือชื่อวิชา (ไทย/อังกฤษ) และกรองตามสถานะได้จากช่องด้านบน พร้อมปุ่ม **"ล้างตัวกรอง"** เพื่อล้างเงื่อนไข

## สถานะของรายวิชา

ระบบจะจัดกลุ่มรายวิชาตามสถานะการประเมิน ดังนี้

* **เปิดให้ประเมิน** — อยู่ในช่วงเวลาที่กำหนด สามารถกดเข้าไปทำแบบประเมินได้
* **นอกช่วงการประเมิน** — ยังไม่ถึง หรือเลยช่วงเวลาที่เปิดให้ประเมินของรายวิชานั้น
* **ยังไม่เปิดให้ประเมิน** — รายวิชาที่ยังตั้งค่าไม่พร้อม (เช่น ยังไม่มีการกำหนดหัวข้อ/ผลลัพธ์การเรียนรู้) จึงยังเข้าทำแบบประเมินไม่ได้
* **ไม่เปิดรับการประเมิน** — รายวิชาที่ไม่ได้เปิดให้ประเมินในระบบ
* **ประเมินแล้ว** — ส่งแบบประเมินเรียบร้อยแล้ว

รายวิชาแต่ละรายการจะแสดงรหัสวิชา ชื่อวิชา ตอน สถานะการทำแบบประเมินทั้ง 3 ประเภท และช่วงวันที่สำหรับการประเมินของรายวิชานั้น ๆ

นักศึกษาสามารถกดที่รายวิชาเพื่อเริ่มหรือทำแบบประเมินต่อ และสำหรับรายวิชาที่ส่งแบบประเมินแล้ว จะแสดงเป็นประวัติการประเมินที่ทำไว้ (ไม่สามารถแก้ไขได้)

{% hint style="info" %}
หากไม่พบรายวิชาที่ลงทะเบียน หรือข้อมูลไม่ถูกต้อง กรุณาติดต่อเจ้าหน้าที่ระดับคณะที่ดูแลรายวิชานั้น ๆ
{% endhint %}
