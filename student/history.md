# Evaluation History ประวัติการประเมิน

<figure><img src="../.gitbook/assets/v2-student-history.png" alt=""><figcaption><p>ประวัติการประเมินรายวิชาที่ส่งแล้ว</p></figcaption></figure>

หน้า **"ประวัติการประเมิน"** จะแสดงรายการแบบประเมินรายวิชาที่ท่าน **ส่งแล้ว** ในรูปแบบตาราง โดยแสดงวันที่ส่ง รายวิชา (รหัสวิชาและชื่อวิชา) และสถานะของแบบประเมิน

ท่านสามารถกดปุ่มดูรายละเอียด (Info) เพื่อเปิดดูแบบประเมินที่ส่งไว้ในแบบอ่านอย่างเดียว (ไม่สามารถแก้ไขได้)

{% hint style="info" %}
ประวัติจะแสดงตามภาคการศึกษาที่ท่านกำลังเลือกอยู่ ท่านสามารถสลับภาคการศึกษาได้จากแถบด้านบนของระบบ
{% endhint %}
