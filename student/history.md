# Evaluation History ประวัติการประเมิน

<figure><img src="../.gitbook/assets/v2-student-history.png" alt=""><figcaption><p>ประวัติการประเมินรายวิชาที่ส่งแล้ว</p></figcaption></figure>

หน้า **"ประวัติการประเมิน"** เก็บรายการแบบประเมินรายวิชาที่ท่าน **ส่งแล้ว** ไว้ในตารางเดียว ดูง่าย บอกวันที่ส่ง รายวิชา (รหัสวิชาและชื่อวิชา) และสถานะของแบบประเมิน

อยากย้อนดูว่าตอบอะไรไป กดปุ่มดูรายละเอียด (Info) เพื่อเปิดดูแบบประเมินที่ส่งไว้ได้เลย โดยเปิดดูได้อย่างเดียว (แก้ไขไม่ได้)

{% hint style="info" %}
ประวัติจะแสดงตามภาคการศึกษาที่ท่านเลือกอยู่ อยากดูเทอมอื่นก็สลับภาคการศึกษาได้จากแถบด้านบนของระบบ
{% endhint %}
